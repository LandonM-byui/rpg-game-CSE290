EFFECT PLANNING:
	IHook : Context hook for an action sequence
		[Before, After]
	IContext : Pure data
	IPostContext : Data describing the result of the action
	IEffect : Effect container
	IModifier : Alters the context data
	ICondition : Special conditions that are tied to context
	ISystem: Translates and modifies data in a consistent way
